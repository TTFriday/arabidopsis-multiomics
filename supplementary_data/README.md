# Supplementary Data Files

This directory contains all data files for Supplementary Tables S1-S14 referenced in the manuscript.

## Files

- **TableS1_data_profile.md** - Complete data profile of all ten tables (Table S1)
- **TableS2_overlap_audit.md** - Cross-layer identifier overlap audit (Table S2)
- **TableS3_autocorrelation.csv** - Spatial autocorrelation of environmental effect size (Table S3)
- **TableS4_clustering.csv** - Clustering statistics by chromosome (Table S4)
- **TableS5a_breadth_effect.csv** - Breadth vs mean effect size strata (Table S5, Part A)
- **TableS5b_orderstat.csv** - Order-statistic comparison of breadth vs effect size (Table S5, Part B)
- **TableS6_locus_architecture.csv** - Per-locus environmental architecture (Table S6)
- **TableS7_regulatory_class.csv** - Regulatory class summary (Table S7)
- **TableS8_trait_class.csv** - Trait class summary (Table S8)
- **TableS9_cooccurrence.csv** - Layer co-occurrence across genes (Table S9)
- **TableS10_trait_panel.csv** - Three-layer convergence trait panel (Table S10)
- **TableS11_layer_panel.csv** - Cohort-matched trait layer panel (Table S11)
- **TableS12_gene_enrichment.csv** - Gene-level pairwise layer enrichment (Table S12)
- **TableS13_env_variable.csv** - Environmental variable summary (Table S13)
- **TableS14_nearest_gene.csv** - Environment-associated genes and nearest-gene assignments (Table S14)
